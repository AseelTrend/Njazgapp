# تطبيق نجاز كارد (Njaz Card) — نسخة React

تطبيق بطاقات رقمية، شحن ألعاب، باقات شبكات الإنترنت والاتصالات، وخدمات الدفع والتحويل.

تمت إعادة كتابة التطبيق من Flutter إلى تطبيق **React 18 + TypeScript + Vite + Tailwind CSS** مع الحفاظ الكامل على كافة الميزات والمنطق البرمجي وتصميم الهوية البصرية.

## المميزات الرئيسية
- **إدارة الحساب والمصادقة**: تسجيل الدخول، إنشاء حساب، دعم التحقق بخطوتين (2FA)، وفحص معرف الجهاز.
- **عرض الرصيد والمحفظة**: بطاقة رصيد مميزة مع إمكانية إظهار/إخفاء الرصيد، إحصائيات الإيداع والمصروف، وسجل كامل للحركات المالية.
- **تصفح الأقسام والخدمات**: تصفح هرمي لجميع أقسام الخدمات (كروت شبكات، يمن موبايل، يو، سبأفون، شدات ببجي، فري فاير، بطاقات هدايا رقمية، سداد فواتير، خدمات جيبي) مع حقول إدخال ديناميكية وحساب فوري للتكلفة.
- **تنفيذ الطلبات واستلام الأكواد**: تنفيذ فوري للطلبات مع فحص كفاية الرصيد، وإنشاء كود تسليم رقمي فوري يمكن نسخه بنقرة زر.
- **بوابة شحن الرصيد المتكاملة**:
  - **تحويل يدوي**: الكريمي إكسبرس، ون كاش، جيب، النجم للحوالات مع حساب فرق العملة ورفع صورة السند.
  - **مباشر USDT BEP20**: توليد عنوان إيداع مخصص مع عداد تنازلي والتحقق برمز الـ TxID.
  - **Binance Pay**: تحويل C2C مع معرف الاستلام والتحقق برقم المعاملة.
  - **محفظة فلوسك**: إرسال وتأكيد برمز التحقق (OTP).
  - **بكود بطاقة**: شحن فوري باستخدام أكواد البطاقات الرقمية.
  - **تحويل شريحة SMS**: دعم مناطق الشمال والجنوب ومزودي الاتصالات.

## التشغيل محلياً
```bash
npm install
npm run dev
```
يعمل خادم التطوير على المنفذ `3000`.
